# Toothouse Dental Website

A clean, responsive Toothouse dental clinic website made with simple:

- HTML
- CSS
- JavaScript

No React, no build step and no complicated dependencies.

## Run it

1. Extract the ZIP.
2. Open `index.html` in a browser.

For local development, VS Code + Live Server is recommended.

## Change clinic information

Open `config.js`.

You can easily change:

- Clinic name
- Phone
- WhatsApp number
- Email
- Address
- Clinic timings
- Google Maps link
- Doctor details
- Services
- FAQs
- Social links

## Important before publishing

1. Replace the sample doctor image with the real doctor's photograph.
2. Replace sample testimonials with genuine patient reviews.
3. Replace placeholder contact information.
4. Change the Google Maps address.
5. Connect the appointment form to a real backend/email/CRM service.
6. Replace the example domain in the SEO metadata.
7. Add real Privacy Policy and Terms & Conditions pages.
8. Compress final clinic images to WebP/AVIF for production.

## WhatsApp

The WhatsApp buttons already work using the number in `config.js`.

Example:
`whatsapp: "919876543210"`

Use the country code without `+` or spaces.

## Appointment form

The form currently gives a confirmation message in the browser. It does NOT store appointments on a server.

The WhatsApp appointment button sends the entered details to WhatsApp.

For real online booking, connect the form to your preferred backend, email service, Google Sheets, CRM or appointment system.
